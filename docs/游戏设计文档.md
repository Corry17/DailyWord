# 修仙路（Tower Game）— 游戏设计文档

> 版本：v1.0
> 日期：2026-08-13
> 模块：DailyWord 内置修仙主题爬塔背单词游戏，通过回答英语题目推进 16 大境界，融合角色养成、装备收集、随从（宠物/精灵）、隐藏职业与成就系统。

---

## 1. 游戏概述

### 1.1 定位

学习型 RPG：**用背单词代替战斗指令**——答对英文题 = 命中敌人，答错 = 挨打。将碎片化背单词转化为有目标的闯关体验，词库与主学习模块（StudyCard）打通：背过的词优先出战、高频词先考。

### 1.2 核心循环

```
选择仙道人物 → 踏上修仙路 → 境界地图选节点 → 答题战斗/事件/商人
   ↑                                        ↓
   └────── 结算（金币/掉落/装备磨损）← 胜利/失败/撤退/死亡
```

### 1.3 词库规则

- 全词库通用（约 1.7 万词），按「已背 → 未背」「高频 → 低频」排序（loadPool）
- 难度随整体进度滑动窗口（difficultyWindow）：越深入修仙路，考的越难
- 启动时后台预热词库（prewarmTowerPool），进入游戏零卡顿
- 分类词池（categoryWords）与分类词数（categoryCounts）缓存：地图生成与出题不扫描全库

## 2. 职业系统

### 2.1 普通职业（仙道页可切换，持久化）

| 职业 | 生命 | 技能 | 效果 |
|------|-----|------|------|
| 词剑士 | 34 | 格挡 | 血厚耐揍；每场战斗第一次答错不扣血 |
| 词法师 | 26 | 咒语连击 & 凝时 | 连对 3 题起每击伤害 +1；限时战时限 +15 秒 |
| 词行者 | 28 | 妙手 | 每场战斗可跳过一题，不扣血不计错 |
| 词医者 | 30 | 回响治疗 | 每连对 2 题回复 1 点生命 |
| 词赌徒 | 22 | 孤注一掷 | 命中伤害 ×2，挨打多掉 1 血 |

### 2.2 隐藏职业：魔修 😈

**不参与人物选择**，以极低概率随机觉醒，平时完全隐藏：

- **自断筋骨** → 1/1000 觉醒
- **闯关失败（死亡）** → 1/10 觉醒并获得一件魔器；否则 1/50 觉醒
- **撤退结束挑战** → 1/50 觉醒
- 觉醒后：生命恒 ≤0（不死不灭）、红黑暗色专属界面风格、专属技能；**魔修身份期间无职业选择**（仙道页只显示魔修身份卡）
- **敌人阵营反转**：魔修视角下敌人多为**正道修士**（仙门弟子/降魔道人/仙门长老/伏魔仙尊等，Boss 名按境界轮换），**15% 概率遭遇同族魔道**（保持原词妖名）；地下墓穴守卫中立不受影响
- **死亡即身份结束**：魔修灰飞烟灭（反噬/Boss 战失败等）后**道体重归凡尘**（恢复初始职业），回到最初的选择界面；后续仍可再次随机觉醒

**魔修技能「不死不灭」**：生命恒为 0 以下（初始 0，永不恢复为正）——
- **不死**：hp ≤ 0 永不死亡（普通判定豁免），挨打继续扣为负值
- **不灭（回血平衡）**：每答对一题**魔气回涌 +1**；**战斗胜利 +3**；**灵泉节点对魔修生效**（魔气滋养 +15，向 0 回升）；装备/精灵治愈同样向 0 回升——负血可稳步回补
- **狂暴**：**负血越深攻击越狂**——每 3 点负血额外 +1 伤害
- **魔气反噬（死亡机制，随机）**：负血越深越危险——受击时按「(-负血-5) × 3%」随机灰飞烟灭（封顶 60%）；负血 -6 起 3%、-10 起 15%、-20 起 45%。**无固定死亡线**，是概率性反噬
- **告知机制**：开局 toast 说明反噬规则；顶栏/仙道页/结算实时显示「🔥 当前负血（反噬 X%）」

**魔器（😈 隐藏品质）**：
- 抽取权重 1（低于金色传说 3），全游戏最难获得
- **条件揭示**：真实名称/图标/描述/渊源存在（幽冥锁链、噬魂刃、魔心、魔纹古玉），但默认以 `?` 示人——**获得（入包/图鉴点亮）或成为魔修时揭示真容**，其余时候一律紫色 ? 剪影（名称 ？？？、不可查看）
- 背包：魔修或已拥有才显示；图鉴：所有职业可见格子，未揭示为紫色 ? 剪影
- **获得时 toast 揭示真名与效果**（如「😈 获得魔器【噬魂刃】：命中伤害 +4」）
- 获得途径：地下墓穴胜利 1/50 掉落；失败觉醒赠送 1 件

## 3. 修仙路与境界

> **关卡系统重设计进行中**：详见 [关卡系统重设计](关卡系统重设计.md)（节点内多关卡、节点间分叉路、更多答题玩法）——待评审后分步实施

### 3.1 16 大境界（凡人 → 道祖）

整条修仙路**一命通关**：生命跨境界共用，境界突破仅小幅提升上限与回复。每境一条独立 S 形弯线地图，节点按楼层推进，BOSS 镇守境末。

### 3.2 地图节点（makeChoices 动态生成）

- **战斗**：普通词妖（随机词类/题型）
- **精英**（捷径）：小 Boss，难但胜利跳过一节点
- **限时试炼**：限时答题
- **灵泉**（休息）：回复 15 血
- **神秘商人**：八折限时道具（24h 过期）
- **岔路**：第 2 节点起 55% 出现「捷径 vs 绕行」二选一
- **地下墓穴**（神秘关卡）：每次进战斗 1/1000 误入，墓穴守卫，胜利 1/50 掉落魔器

### 3.3 Boss 技能（梗 Boss，16 境各具特色）

| 能力 | 效果 |
|------|------|
| 封印 | 本局职业技能失效（如鸡哥 rap 封印） |
| 双倍扣血 | 答错伤害 ×2（如马保国闪电五连鞭） |
| 时间吞噬 | 答错额外扣限时 5 秒 |
| 回血 | 每答 3 题回复 1 血 |
| 不死身法 | Boss 战中 hp 归 0 不死（对应特殊机制） |

### 3.4 突发事件（22% 概率，每境楼层间）

- **强制迎战（forced）**：不可拒绝、**不可撤退**
- **秘宝洞窟（opportunity）**：可选，胜利掉落物品，35% 附带诅咒扣血
- **灵光（trial）**：限时灵光考验

### 3.5 撤退与放弃

- **撤退**：普通战斗可撤退（Boss/强制战斗不可）→ 游戏内确认层（非系统弹窗）→ 随机损失：金币（3+floor）、生命（1~floor/2）、装备耐久（按品阶分级磨损）、随从状态、1/10000 概率掉落装备
- **自断筋骨**：修仙路进行中放弃重开（保留背包/装备），1/1000 觉醒魔修
- 窗口关闭（三击顶栏/快捷键/红点）：保存进度；战斗中倒计时暂停，重开继续

## 4. 战斗系统

### 4.1 四种题型

| 题型 | 说明 |
|------|------|
| 英选中（enToCn） | 看英文选中文释义 |
| 中选英（cnToEn） | 看中文选英文 |
| 拼写（spell） | 首字母提示拼写 |
| 英释选词（engDef） | 看英文释义选词 |

### 4.2 战斗流程

- 答对：命中敌人（基础伤害 + 职业/装备/魔化加成）
- 答错：挨打（敌人攻击 - 防御，Boss 能力加成）
- 护盾/跳过/时之沙等职业与道具技能
- 限时战：倒计时归零 → 失败结算
- 胜利结算：金币 + 掉落（秘宝/墓穴魔器）+ 随从回血

### 4.3 随从系统（宠物/精灵）

- 宠物（🐾）与精灵（✨）作为**随从**携带出战，**不是装备**
- 拥有独立**跨战斗、跨会话的永久血量**（petHP/spriteHP，UserDefaults 持久化）
- 撤退会受伤（随机 1~3 血），血量归零随从离去
- 状态词区分：穿戴/武器 = **耐久**；宠物 = **饱食度**；精灵 = **灵力**

## 5. 物品与经济

### 5.1 品质体系（七阶）

低阶 < 中阶 < 高阶 < 稀有 < 传奇 < 金色传说 < **魔器 😈**（隐藏）

抽取权重：28/26/20/14/9/3/1；稀有以上有境界门槛（stageGate）

### 5.2 物品大类

- **穿戴**：帽子/衣服/首饰/裤子/鞋子（五部位）
- **武器**：伤害加成
- **药水**：回血/时之沙
- **随从**：宠物（饱食度）/ 精灵（灵力）
- 装备职业限定（36 件）、装备耐久按品阶分级磨损、限时道具（商城永久/商人 24h/秘宝 48h）

### 5.3 经济

- 金币：战斗胜利/突破奖励，永久留存
- 神秘商人（局内八折）、云间商城（定时 + 金币双刷新）
- 246+ 件物品 + 图鉴收集

## 6. 成就与等级联动

- **仙途成就独立面板**：游戏成就**不在学习面板成就总览展示**，独立展示于游戏界面（仙道页"🏔️ 仙途成就"按钮 → 成就网格面板，`RewardEngine.towerAchievements()` 提供数据）；XP 仍计入主等级体系
  - **递进成就体系**（由简到难，全 22 个）：
    - 闯关：初入仙途（首战 +50）→ 首战告捷（首胜 +80）→ 十战十胜（10 胜 +150）→ 二十连胜（20 胜 +120）→ **五十战雄（50 胜 +250）→ 百战宗师（100 胜 +400）**
    - 图鉴：**图鉴小成（50 件 +100）→ 图鉴大师（150 件 +200）→ 全图鉴（250 件 +400）**
    - 墓穴：**墓穴探险（通关 1 次 +80）**——墓穴为低概率遭遇，不做多次数递进
    - 登顶：**角色登顶×6**（各角色通关全部境界，各 +300）→ 问道巅峰（任意通关 +500）→ **万法归一**（全角色登顶 +1000，终极隐藏）
    - 魔修隐藏（紫色 **？？？** 问号）：魔气觉醒（化身魔修 +100）/ 魔修登顶（以魔修通关 +400）/ 魔器齐集（4 件魔器 +200）
- 游戏 XP 计入主应用等级体系（200 + (level-1)×120，100 级上限）

## 7. 界面与交互

- **顶栏 HUD**：境界/楼层/生命/金币/魔化状态
- **仙道页**：人物切换卡（魔修隐藏）+ 踏上修仙路入口 + 自断筋骨
- **地图**：单境 S 形弯线 + 节点勋章 + 分支标注
- **战斗**：敌人卡（血量条/词类）+ 题目卡 + 四选项 + 技能栏（格挡/苦肉已移除/时之沙）
- **魔修专属**：红黑暗色主题 + 橙色 tint + 深色模式
- **窗口**：三击顶栏关闭（保存进度）、⌥G 快捷键开关
- 背包/图鉴：横向 Tab 分类；魔器仅魔修可见

- 控制型：封印（技能失效）/ 时间吞噬（答错 -5s）
- 攻击型：双倍扣血 / 毒雾漫天（答对被侵蚀 1 血）/ 狂暴之血（每 3 题攻击 +1）/ 吸血魔功（答错回复 1 血）

**设计要点**：血量按玩家装备成长对照提升（12 → 450，约 ×4~6 于旧值）；**限时选择性**——7 境限时（快节奏 Boss）、9 境不限时（持久战 Boss）；后期 Boss 攻击/防御型技能混合，考验答题质量与持久力。

## 8. 技术要点

- 架构：MVVM + Phase 状态机（realm/map/battle/event/merchant/stageClear/defeat...）
- 引擎：TowerGameEngine（@MainActor ObservableObject）唯一核心
- 持久化：UserDefaults（tower 前缀键）；进度存档 towerSave（境界/楼层/血量）
- 性能：词库启动预热、分类缓存（categoryWords/categoryCounts）、出题零全库扫描
- 计时：窗口关闭暂停（towerBattleTimeLeft），重开恢复
