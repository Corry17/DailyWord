# DailyWord 版本与分支记录

## 记录边界

本仓库由两份本地源码目录导入。两份目录均没有项目级 `.git`，无法恢复原始逐次提交、原分支名称、作者时间线或合并记录。

以下记录只表示本次归档时实际存在的文件快照。旧版和最终版的身份由项目作者指定，不根据目录名中的备份日期、文件修改时间或功能多少推断；提交使用实际导入时间，不伪造旧日期。

## 实际差异摘要

`git diff --stat snapshot-legacy snapshot-final` 显示：26 个文件变化，增加 1,147 行，删除 4,731 行。这个统计反映两份目录的差异，不表示本次归档主动重写了应用功能。

- 应用服务、设置、数据导入导出、上手引导、练习、游戏、学习面板和翻译模块存在版本差异。
- 旧版中的 `SelectedTextReader.swift`、`BackupArchive.swift`、`OnboardingProgress.swift`、`ShortcutBinding.swift`、`TranslationRequest.swift`、`WordRootCatalog.swift` 不在作者指定的最终版中，仍可从旧版分支查看。
- 测试执行器与三份设计文档存在差异；不能将旧版测试覆盖范围直接视为最终版覆盖范围。
- 两份快照的预置词库、`Package.swift`、`Package.resolved`、词库构建脚本和物品生成脚本一致。
- 本次归档未合并旧版独有功能到最终版，也未修改最终版业务源码。

## 查看与比较

在完整克隆的仓库中执行：

```bash
git fetch origin --tags
git branch -a
git tag --list
git log --all --graph --decorate --oneline

# 比较旧版与最终版
git diff --stat snapshot-legacy snapshot-final
git diff snapshot-legacy snapshot-final -- Sources/DailyWord/DataTransferManager.swift

# 只查看旧版文件，不修改当前工作区
git show snapshot-legacy:Sources/DailyWordCore/Database/BackupArchive.swift

# 查看最终版之后的仓库整理变更
git diff --stat snapshot-final main
```

GitHub 上可通过仓库的分支切换器、标签列表和 Commits 页面查看对应版本。归档分支与标签用于固定快照，后续开发提交放在主线或新的功能分支。
